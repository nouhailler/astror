Écran À propos

Description

Accessible tout en bas du menu hamburger, cet écran regroupe les informations d'identification de l'application, les liens du développeur et les moyens de contact.

Objectif

Permettre à l'utilisateur de connaître la version exacte installée, de contacter le support avec les informations utiles déjà réunies, et de retrouver les liens officiels (dépôt, documentation, portfolio).

Prérequis

Aucun pour consulter les informations. Les liens de contact ouvrent respectivement le client mail et GitHub.

Comment l'utiliser

Menu ☰ → faire défiler jusqu'en bas → « À propos ».

Contenu

BlocContenu
VersionNuméro de version (package.json), SHA de commit court, date de publication du build
DéveloppeurPatrick Nouhailler ; lien vers swinux.ch ; lien vers le portfolio des applications

Informations de diagnostic incluses automatiquement

Les liens « Contacter le support » et « Signaler un bug » pré-remplissent le corps du message avec :

  • Version de l'app et SHA de commit
  • Date de build
  • Mode (application installée / navigateur)
  • Plateforme et langue
  • Chaîne navigator.userAgent complète (navigateur, moteur, système)

Données utilisées

Aucune donnée n'est envoyée automatiquement : les liens ouvrent le client mail ou GitHub avec un message pré-rempli que l'utilisateur peut relire, modifier et envoyer lui-même (ou ne pas envoyer).

Résultat

Un message de support ou une issue GitHub déjà structuré, sans que l'utilisateur ait à chercher lui-même sa version ou son appareil.

Fonctionnement hors connexion

L'écran s'affiche entièrement hors ligne (aucune donnée réseau requise). Les actions « Contacter le support » et « Signaler un bug » nécessitent une application de messagerie ou une connexion Internet pour aboutir.

Limites

Il ne s'agit pas d'un envoi automatique et silencieux de télémétrie : l'utilisateur doit valider et envoyer lui-même le message pré-rempli (mail ou issue GitHub), conformément à l'absence de collecte de données en arrière-plan (voir Données et confidentialité).

Erreurs possibles

Aucune identifiée. Si l'appareil n'a pas de client mail configuré, le lien « Contacter le support » peut ne rien ouvrir — utiliser alors « Signaler un bug » (GitHub) ou écrire directement à contact@swinux.ch.
