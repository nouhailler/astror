Tous les paramètres

L'écran Paramètres édite directement le même profil que l'onboarding — chaque modification est appliquée et enregistrée immédiatement, sans bouton « Enregistrer » (sauf mention contraire ci-dessous).

Intelligence artificielle

ParamètreTypeDéfautApplication
Clé API OpenRouterTexte masquéVideEnregistrée dès le clic sur « Modèles gratuits » (avant même la validation)
Modèle OpenRouterSélection dans une liste dynamique (modèles « :free »)AucunImmédiate au clic sur un modèle
Clé API AnthropicTexte masquéVideBouton « Enregistrer » explicite ; bouton « Tester » ne sauvegarde pas

Priorité d'utilisation : OpenRouter (si clé + modèle) → Anthropic (si clé) → sinon fonctionnalités IA indisponibles. Détail : Clés API pour l'IA.

À vérifier

aucun bouton dédié ne permet d'effacer isolément une clé API déjà enregistrée (voir Limites dans « Clés API pour l'IA ») ; il n'a pas non plus été confirmé si « Revoir l'introduction » pré-remplit les étapes avec le profil actuel ou repart des valeurs par défaut.
